# startbootstrap-clean-blog-jekyll
## Project Description
This project is a blog theme by Start Bootstrap with a Flask app to generate articles about South African plants.
## Key Features
- Generate articles about South African plants using a Flask app
- Save generated articles as Jekyll posts
- Display posts on a blog page
## Tech Stack
- Flask
- Jekyll
- Bootstrap
- HTML/CSS/JS
## Installation
1. Clone the repository: `git clone https://github.com/your-username/startbootstrap-clean-blog-jekyll.git`
2. Install required packages: `pip install -r requirements.txt`
3. Run the Flask app: `python app.py`
## Usage
1. Open a web browser and navigate to `http://localhost:5000`
2. Enter a plant name in the search bar and click the "Generate Article" button
3. The generated article will be saved as a Jekyll post and displayed on the blog page
## Environment Variables
- `POSTS_DIR`: the directory where Jekyll posts are stored
- `site.title`: the title of the blog
- `site.description`: the description of the blog
- `site.baseurl`: the base URL of the blog
- `site.url`: the URL of the blog
- `site.google_analytics`: the Google Analytics ID
